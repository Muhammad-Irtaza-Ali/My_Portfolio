Explore a student document-search prototype. Use the public university example or upload your own text, then search for relevant passages.

This browser demo searches TXT and Markdown documents. It retrieves original excerpts using keyword ranking; it does not generate answers or provide official university advice. The Python version in GitHub additionally supports text-based PDFs.

1. Add documents

Files are processed inside this browser tab. This demo does not upload document contents to a server or AI provider.

    Use public or approved documents. UTF-8 text is supported. Reloading closes the document collection; no persistent storage is used.
