Image captioning

Connecting images and language.

Explore a ViT–GPT2 image-captioning workflow with a Gradio interface. This project applies a pretrained vision-language model to generate descriptions of images.

Inside the project
Workflow
Image → description
Purpose
An image is processed by a pretrained vision-language model to produce a text caption.
Approach
The README describes a ViT encoder, GPT-2 text generation, and a Gradio interface.
What to know
Explore the implementation and documentation in the repository. Caption quality can vary; generated descriptions need review.

02 / COMPUTER VISION · INTERACTION

Air Canvas

Draw with a gesture.

A webcam-based drawing application using OpenCV and MediaPipe hand tracking. Finger movements become strokes, with gesture controls for color selection and clearing the canvas.

Inside the project
Workflow
Webcam → hand landmarks → strokes
Purpose
A drawing experiment that translates tracked hand movement into marks on a digital canvas.
Approach
OpenCV captures video; MediaPipe tracks hand landmarks for drawing and gesture controls.
What to know
The repository includes versions with and without OCR. Camera setup and local execution are needed to explore the application.
Python · OpenCV · MediaPipe
